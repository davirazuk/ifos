  LAUNCHING
    Mod + Return           terminal (alacritty)
    Mod + d                application launcher
    Mod + e                file manager
    Mod + g                IFOS Launcher — tela cheia: jogos, escola, Moodle
    Mod + Esc              gerenciador de tarefas — processos e desempenho
    Mod + n                luz noturna (liga/desliga o filtro de luz azul)
    Mod + Shift + a        IFOS Software — install apps on demand
    Mod + Shift + i        install IFOS to disk
    Mod + F1               this cheatsheet

  WINDOWS
    New windows open as TABS, not splits - opening an app never rearranges
    what you already have open. Mod+B / Mod+V split deliberately.

    Mod + q                close window
    Mod + Shift + q        close window
    Alt + Tab              window switcher
    Mod + ← / →            previous / next tab
    Mod + h j k ;          focus left / down / up / right   (arrows work too)
    Mod + Shift + h j k ;  move window
    Mod + f                fullscreen
    Mod + Shift + space    float / unfloat
    Mod + r                resize mode (Enter or Esc to leave)
    Mod + b / Mod + v      split horizontal / vertical
    Mod + s / w / t        stacking / tabbed / toggle split

  WORKSPACES
    Mod + 1..9             go to workspace
    Mod + Shift + 1..9     move window to workspace
    Mod + Tab              back and forth
    Mod + Ctrl + ← / →     previous / next workspace

  SESSION
    Mod + l                lock the screen (auto-locks after 10 min idle)
    Mod + Shift + e        power menu (lock, log out, suspend, restart, shut down)
    Mod + Shift + c        reload i3 configuration
    Mod + Shift + r        restart i3 in place

  SCREENSHOTS
    Print                  whole screen  → ~/Pictures/screenshots + clipboard
    Shift + Print          select a region → file + clipboard
    Alt + Print            active window → file + clipboard
    Ctrl + Print           select a region → clipboard only

  HARDWARE KEYS
    Volume / mute keys     PipeWire volume, with an on-screen indicator
    Brightness keys        backlight, with an on-screen indicator
    Media keys             play / pause / next / previous
    Mod + Shift + m        audio mixer (pavucontrol)

  NO TERMINAL (fish)
    ifos                   menu de comandos do IFOS
    ifos apps              instalar programas
    ifos escola            Moodle e sistemas do IFMS
    ifos jogos             seção de jogos
    ifos atalhos           esta lista
    extract <arquivo>      extrair qualquer arquivo compactado
    mkcd <dir>             criar um diretório e entrar nele
    up 2                   subir dois diretórios

  USEFUL COMMANDS
    ifos-launcher          full-screen launcher (games, school, Moodle)
    ifos-software          install browsers, games, drivers, office, dev tools
    install-ifos           install IFOS to disk (live medium)
    install-yay            enable AUR access
    ifos-update            update the system and pull the latest IFOS from GitHub
    ifos-post-install      re-apply IFOS defaults on an installed system
    nmtui                  text-mode network configuration
    fastfetch              system information
